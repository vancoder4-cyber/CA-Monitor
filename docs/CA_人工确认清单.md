# 公司行动人工确认清单

> 实时待确认事项以生产网站、群内推送和 `@CA问答助手 风险` 为准。不要保存或照抄一次性静态异常名单。

以下命令示例按群聊书写；私聊 Bot 时可省略 `@CA问答助手`。

> 隐私提醒：当前确认/观察的操作员身份和自由备注会写入公开 Git。备注只能写核对依据，不得包含客户、账户、持仓、密钥或内部合同信息。

## 1. 先判定状态

| 状态 | 可以做什么 | 不可以做什么 |
|---|---|---|
| 单源预测核验 | 查公司是否正式宣告，找第二独立来源 | 不执行，不把预测值当正式值 |
| 公司行动条款核验 | 打开 SEC 原文，确认公司行动或普通备案 | 不把疑似 6-K 当成正式执行项 |
| 合约门槛核验 | 补金额、比例、币种、单位和参考价 | 数据不足时不能写无需操作 |
| 单源金额 | 打开公司公告/IR 后再确认 | 不能只凭普通数据商或 Nasdaq 页面确认 |
| 各源不一致 | 对比官方字段和所有来源，保留证据 | 不能随意选择一个聚合页数字 |
| 数据空缺 | 确认事件真实性及该源覆盖能力 | 不能把网络失败理解为没有事件 |
| 合约 `≤3%` | 记录「本次无需操作」 | 不进入合约重复催办 |
| 合约 `>3%` | 进入合约动作和负责人催办 | 不跳过参考价及单位复核 |

## 2. 通用核对项

- [ ] ticker 和公司名称正确；别名已规范化。
- [ ] 事件类型正确：现金分红、送股、拆股、合股或结构性 filing。
- [ ] 主日期正确：分红除息、拆合股生效、filing 事件日。
- [ ] 宣告日、登记日、派发日或交割日已分别核对。
- [ ] 金额为税前毛额，币种明确。
- [ ] 单位明确：每股、每 ADS/ADR 或每份 ETF。
- [ ] 拆/合股比例使用完整 `新股数:旧股数`。
- [ ] 现货与合约动作分别判断。
- [ ] 官方 URL 和第三方交叉核对 URL 已留存。

## 3. 证据顺序

1. 公司官方本次公告 / IR。
2. 精确 SEC filing。
3. 公司长期分红/公司行动页面。
4. SEC 公司备案入口。
5. StockAnalysis 等第三方只作交叉核对。

官方日期已经确认，不代表单一供应商金额自动通过门禁。官方页面本身必须包含对应金额或比例，或者至少两个独立来源一致。

## 4. 确认金额或比例

现金：

```text
@CA问答助手 确认 AAPL 0.26 2026-08-11 已核公司公告
```

拆/合股：

```text
@CA问答助手 确认 XYZ 1:10 2026-09-10 已核 SEC 原文
```

- [ ] 操作员已在 `LARK_WRITE_ALLOWED_OPEN_IDS` 白名单。
- [ ] 日期对应正确事件类型。
- [ ] 同日若存在多个事件，输入足以唯一定位。
- [ ] 现金/送股值是普通十进制的有限正数；没有使用空值、0、负数、科学记数或千分位。
- [ ] 拆/合股使用冒号分隔的完整 `新股数:旧股数`，没有只填单一因子或使用 `1-10` / `1 for 10`。
- [ ] 回执明确写入成功，不是「仅留痕、未生效」。
- [ ] 下一轮流水线已经重算金额门禁和 3% 产品结论。
- [ ] 网站、定时 Lark 和 Bot 查询结果一致。

## 5. 结案 SEC 条款核验

从卡片复制完整 event_id：

```text
@CA问答助手 确认备案 <从卡片复制的完整 event_id>
@CA问答助手 排除备案 <从卡片复制的完整 event_id>
```

event_id 结构为 `TICKER|filing|YYYY-MM-DD|12位十六进制指纹`；不要自行拼接，也不要使用示意值。

- [ ] 没有手输、截短或多输入字符。
- [ ] 已打开卡片对应 SEC 原文。
- [ ] 结论只有一个：公司行动或普通备案。
- [ ] 同日多份 filing 没有被一起宽泛关闭。
- [ ] 确认公司行动后，现货/合约后续动作已重新生成。
- [ ] 排除后明确「普通备案 / 本次无需操作」，且未触发正式 @。

同一句同时包含「公司行动」和「普通备案」会被系统拒绝。未决 filing 超过 30 天只会停止日报并归档，仍然是「未核实」，不能当成无需操作。

预测观察另用 `观察 CODE YYYY-MM-DD [备注]`；操作员必须自行确认日期真实有效且仍在未来。当前写入口不会强制检查日历有效性或未来性，无效/过期记录可能留下公开审计痕迹，但不会作为执行依据。

## 6. 合约 3% 复核

- [ ] 现金使用每股税前毛额。
- [ ] 参考价为前一完整交易日未调整收盘价，且未过期。
- [ ] ADR/ADS 金额与美股报价为同一币种和证券单位。
- [ ] 送股按新增股份比例计算。
- [ ] 拆/合股按完整新旧比例计算。
- [ ] 比较使用未舍入值。
- [ ] `>3%` 才需操作；`≤3%` 无需合约操作。

当前参考价仍是外部市场价，不是内部合约实际 Index/结算价；临界事项须人工对照内部口径。

## 7. 完成后复核

```text
@CA问答助手 留痕 CODE
@CA问答助手 查 CODE
```

- [ ] 留痕中有正确记录。
- [ ] GitHub 写回后的生产 Action 已运行。
- [ ] Pages schema v4、source SHA、run id、delivery 和有效期正常。
- [ ] 定时推送没有同一卡重复或错误 @；现货/合约/双覆盖标的分别命中对应负责人组。
- [ ] `查 CODE` 显示同一官方来源、日期和值。

完整流程见 [CA Monitor 全量操作手册](../OPERATIONS_MANUAL.md)。
